# FitTracker — трекер спортивных упражнений

**Тренируйтесь осознанно: техника, таймер и история прогресса — в одном приложении.**

FitTracker помогает спортсменам планировать тренировки, правильно выполнять упражнения и видеть, как растут результаты. Выберите упражнение, посмотрите анимацию техники, запустите таймер и записывайте каждый подход — всё остальное приложение сделает за вас.

## Для кого

Для тех, кто тренируется регулярно: от новичков в зале до опытных атлетов, бегунов и любителей растяжки. Для спортсменов, которым важно не просто «позаниматься», а видеть прогресс.

## Что умеет FitTracker

### База упражнений
Силовые, кардио и растяжка. У каждого упражнения есть описание, группа мышц, уровень сложности, анимация техники и видео. Каталог загружается из сети, так что новые упражнения появляются без обновления приложения.

### Тренировка с анимированным таймером
Перед каждым подходом — красивый обратный отсчёт, чтобы вы успели занять позицию и собраться. Во время тренировки видна анимация правильной техники выполнения.

### История тренировок
Все занятия в одном месте: дата, время начала и окончания, длительность, заметки, упражнения и подходы. Подход фиксирует повторения, вес в килограммах, а для кардио — время и расстояние.

### Напоминания
Назначьте время — и приложение напомнит о тренировке по расписанию, чтобы вы не пропускали занятия.

### Видео и фотоотчёты
Прикладывайте видео и фото к тренировкам: сравнивайте технику и наблюдайте за изменениями.

### Персональные цели
Выберите цель — **похудение**, **набор массы** или **поддержание формы** — и ведите тренировки под неё.

## Экраны

| Экран | Что на нём |
|---|---|
| Упражнения | Каталог упражнений с описанием и сложностью |
| Тренировка | Анимированный таймер и подходы |
| История | Список прошлых тренировок с деталями |
| Профиль | Пользователи, цель, тема, напоминания |

## Структура данных

| Сущность | Поля |
|---|---|
| `User` | имя, цель (похудение / набор массы / поддержка) |
| `Exercise` | название, описание, категория (силовое / кардио / растяжка), группа мышц, сложность, URL анимации техники, URL видео |
| `Workout` | пользователь, дата, время начала, время окончания, длительность, заметки |
| `WorkoutExercise` | тренировка, упражнение, порядковый номер |
| `Set` | упражнение в тренировке, номер подхода, повторения, вес (кг), длительность (сек, для кардио), расстояние (м) |

## Технологии

- Android, Kotlin, Jetpack Compose (Material 3)
- Архитектура MVVM, Navigation Compose
- Room — локальная база данных, SharedPreferences — настройки
- REST API — загрузка списка упражнений
- WorkManager / AlarmManager — напоминания
- ExoPlayer и Lottie — видео и анимации

## Статус разработки

Проект учебный, развивается поэтапно.

- Готово: каркас приложения, нижняя навигация, экраны
- Готово: локальная база Room: пользователи, упражнения, тренировки, упражнения тренировки, подходы (добавление, просмотр, изменение, удаление)
- Готово: настройки в SharedPreferences: текущий пользователь, тема, длительность отсчёта, напоминания
- В планах: загрузка упражнений из сети
- В планах: таймер с анимацией
- В планах: уведомления по расписанию
- В планах: анимации техники, видео и фотоотчёты

## Как запустить

1. Склонируйте репозиторий: `git clone https://github.com/Semenovaanzhelika31/fitness-tracker.git`
2. Откройте папку в Android Studio (Ladybug или новее, JDK 17).
3. Дождитесь синхронизации Gradle и запустите конфигурацию `app` на эмуляторе или телефоне (Android 8.0+).
