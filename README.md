# Фитнес-трекер (Трекер спортивных упражнений)

Приложение для спортсменов и любителей фитнеса, позволяющее отслеживать тренировки, вести дневник упражнений и контролировать прогресс. Проект разработан с учетом требований магазина приложений RuStore.

##  Целевая аудитория
Спортсмены, фитнес-энтузиасты и люди, ведущие здоровый образ жизни.

##  Основной функционал (Экраны)

1. **Список упражнений:** Каталог упражнений с фильтрацией по категориям (силовые, кардио, растяжка), группам мышц и сложности. Загрузка данных происходит по сети.
2. **Тренировка:** Экран активной тренировки с анимированным таймером обратного отсчета перед подходом, отображением анимаций техники выполнения упражнений.
3. **История тренировок:** Дневник завершенных тренировок с возможностью просмотра статистики и заметок.

##  Модель данных (Сущности)

*   **User:** Имя, цель (похудение / набор массы / поддержка).
*   **Exercise:** Название, описание, категория (силовое/кардио/растяжка), группа мышц, сложность, URL анимации техники, URL видео.
*   **Workout:** Пользователь, дата, время начала, время окончания, длительность, заметки.
*   **WorkoutExercise:** Тренировка, упражнение, порядковый номер.
*   **Set:** Упражнение в тренировке, номер подхода, повторения, вес (кг), длительность (сек) для кардио, расстояние (м).

##  Особенности приложения

*   **Сеть:** Получение актуального списка упражнений с описанием.
*   **Уведомления:** Напоминания о тренировках по расписанию.
*   **Медиа:** Анимации упражнений, возможность прикреплять видео и фотоотчеты к тренировкам.
*   **Анимация:** Плавный анимированный таймер обратного отсчета.

##  Соответствие требованиям RuStore

В ходе разработки учтены следующие правила магазина:
*   Приложение является **нативным** (не использует WebView) и имеет оригинальное наполнение.
*   Соблюдены правила работы с **чувствительными разрешениями** (камера, уведомления запрашиваются только по мере необходимости с обоснованием).
*   Название и иконка не содержат кликбейта и чужих товарных знаков.
*   Приложение работает стабильно и адаптировано под современные мобильные устройства.

##  Как запустить проект

1. Клонируйте репозиторий.
2. Откройте проект в **Android Studio**.
3. Соберите проект (Gradle Sync -> Build APK).
4. Запустите на эмуляторе или физическом устройстве (Android 8.0+).
