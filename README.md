# FitTracker — трекер спортивных упражнений 

**FitTracker** — это мобильное приложение для спортсменов, которое помогает планировать тренировки, отслеживать прогресс и правильно выполнять упражнения благодаря анимациям техники.

---

##  О проекте

Приложение разработано для людей, ведущих активный образ жизни: от новичков до опытных атлетов. FitTracker объединяет в себе базу упражнений, удобный таймер тренировок и подробную историю занятий.

### Целевая аудитория
Спортсмены, фитнес-энтузиасты, люди, следящие за своим здоровьем и физической формой.

---

##  Основные возможности

-  **База упражнений** — силовые, кардио и растяжка с описанием, группой мышц, сложностью и анимацией техники выполнения.
-  **Тренировка с таймером** — анимированный обратный отсчёт перед каждым подходом.
-  **История тренировок** — просмотр всех выполненных тренировок с детальной статистикой.
-  **Напоминания** — уведомления о запланированных тренировках по расписанию.
-  **Медиа** — анимации упражнений, видео и фотоотчёты.
-  **Персональные цели** — похудение, набор массы или поддержание формы.

---

##  Структура данных

| Сущность | Описание |
|----------|----------|
| **User** | Пользователь: имя, цель (похудение / набор массы / поддержка) |
| **Exercise** | Упражнение: название, описание, категория, группа мышц, сложность, URL анимации, URL видео |
| **Workout** | Тренировка: пользователь, дата, время начала/окончания, длительность, заметки |
| **WorkoutExercise** | Связь тренировки и упражнения с порядковым номером |
| **Set** | Подход: номер, повторения, вес (кг), длительность (сек), расстояние (м) |

---

##  Экраны приложения

1. **Список упражнений** — каталог с фильтрацией по категории и группе мышц.
2. **Тренировка** — таймер с анимацией техники выполнения упражнения.
3. **История тренировок** — список прошлых тренировок с деталями.

---

##  Технологии

- **Платформа:** Android (Kotlin)
- **IDE:** Android Studio
- **Сеть:** REST API для загрузки списка упражнений
- **Уведомления:** AlarmManager / WorkManager
- **Медиа:** ExoPlayer, Lottie (анимации)
- **Архитектура:** MVVM
